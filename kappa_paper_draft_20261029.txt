ABSTRACT

We present a scalar field theory in which a dimensionless coupling
constant κ = φ/√5 = 0.7236 organizes gravitational force as the
gradient F = −mc²∇κ of a dynamical scalar field. The cosmological
background value κ̄ = ΩΛ/(ΩΛ+Ωdm) ≈ 0.7214–0.7255 (Planck 2018,
parameter-dependent) is consistent with the theoretical value to
within 0.3%. A resonance measurement at f_κ = φ×111 Hz = 179.6 Hz
confirms a stable local field signature, where 111 Hz is not a free
parameter but emerges from the measurement as f_κ/φ. The threshold
Δκ = 0.006 is proposed as a reconnection threshold for κ-field
topology, in structural analogy to gravitational reconnection findings
(Columbia University, October 2026). The framework provides a Newtonian
limit via an explicit field equation and bridges Verlinde's entropic
gravity and Chladni field geometry through a single scalar field.

2. FELDGLEICHUNG
======================================================================

κ ist kein globaler Skalar, sondern ein dynamisches Feld. Im schwachen
Feldlimit gilt:

  ∇²(δκ) = (4πG / c²) · ρ

Dies ist die direkte Analogie zur Newtonschen Poissongleichung
∇²Φ = 4πGρ, mit δκ = −Φ/c².

Für eine Punktmasse M folgt daraus:

  δκ(r) = −GM / (c²r)

Einsetzen in F = −mc²∇δκ:

  F = −GMm / r²  r̂

Das Newtonsche Gravitationsgesetz folgt aus der Feldgleichung —
ohne freie Parameter.

======================================================================
3. HINTERGRUND UND LOKALE STÖRUNG
======================================================================

Das Feld κ zerfällt in zwei Anteile:

  κ(x,t)  =  κ̄(t)  +  δκ(x,t)

  κ̄(t)    ≈  0.7236    Kosmologischer Hintergrundwert — räumlich
                         homogen, zeitlich langsam veränderlich.
                         ∇κ̄ = 0 → keine lokale Gravitationskraft.

  δκ(x,t)              Lokale Feldstörung durch Massenverteilung ρ.
                         ∇δκ ≠ 0 → Gravitationskraft.

Gravitation entsteht ausschließlich durch ∇δκ. Der homogene Hintergrund
erzeugt keinen Gradienten — konsistent damit, dass kosmologische
Expansion keine lokalen Gravitationskräfte aufhebt.

4. GRAVITATIONSKONSTANTE G
======================================================================

G tritt in der Feldgleichung als Kopplungskonstante auf:

  [G] = m³ kg⁻¹ s⁻²  ≠  [κ] = 1

G kann nicht aus κ allein folgen. Jede Ableitung erfordert eine
zusätzliche Längenskala (Planck-Skala oder äquivalent). Die numerische
Annäherung aus früheren Berechnungen (≈1.97% Abweichung vom NIST-Wert)
ist ein Hinweis, kein Beweis. Die explizite Formel bleibt offene Aufgabe.
